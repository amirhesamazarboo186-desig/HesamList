# HesamList

یک وب‌اپ فارسی و واکنش‌گرا برای ساخت لیست خرید و وسایل سفر و همکاری همزمان با دوستان.

## امکانات
- ثبت‌نام و ورود با ایمیل و رمز عبور
- ساخت لیست «خرید» یا «سفر»
- اضافه/حذف/تکمیل کردن موارد
- فیلتر همه / باقی‌مانده / انجام‌شده
- دعوت اعضا با ایمیل
- نقش‌های Owner / Admin / Editor / Viewer
- محدود کردن افزودن، حذف و ویرایش بر اساس نقش
- همگام‌سازی ابری با Supabase
- آماده برای Realtime روی جدول items
- رابط کاربری کاملاً responsive برای موبایل و لپ‌تاپ
- پنل مدیریت کاربران برای مدیر اصلی
- نسخه Demo محلی در صورت وارد نکردن کلیدهای Supabase

## فعال‌سازی نسخه واقعی
1. در Supabase یک پروژه بساز.
2. محتوای `supabase.sql` را کامل در SQL Editor اجرا کن.
3. در `config.js` مقدار `supabaseUrl` و `supabaseAnonKey` را قرار بده.
4. در تنظیمات Auth، Email provider را فعال کن.
5. جدول `items` را در Realtime فعال کن.
6. فایل‌های همین پوشه را روی هر هاست استاتیک مثل Netlify، Vercel یا GitHub Pages قرار بده.
7. بعد از اولین ثبت‌نام، UUID کاربر خودت را از Authentication > Users بردار و دستور آخر `supabase.sql` را اجرا کن تا مدیر اصلی شوی.

## نکته
بدون تنظیم Supabase، سایت به صورت Demo محلی کار می‌کند؛ اطلاعات بین دستگاه‌های مختلف در این حالت مشترک نیست. برای همان قابلیت اصلی که می‌خواهی—چند دوست با گوشی و لپ‌تاپ‌های مختلف—باید Supabase را متصل کنی.
